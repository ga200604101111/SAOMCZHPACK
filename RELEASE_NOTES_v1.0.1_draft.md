# SAOMCZHPACK v1.0.1 — Open-Font Rebuild (DRAFT)

**Do not publish before verifying all remaining third-party redistribution rights and in-game visuals.**

Main resource ZIP: \`SAO_ZH_Pack_v1.0.1_public_candidate.zip\`.

Changes:
- The private V9 ZIP has been left completely unchanged.
- The three proprietary Windows fonts (Microsoft JhengHei Regular/Bold and DFKai-SB) are **not** included.
- Two new, renamed static font subsets derived from the official open-source Noto Sans CJK TC are included, under SIL OFL 1.1.
- All 26 formerly Microsoft-derived Chinese MSDF glyph atlases have been regenerated from Noto fonts.
- Original SAOUI/SaoJob Latin font pixels were freshly sourced from the installed mod JARs; separate third-party font licenses from the original mod are included.
- A THIRD_PARTY_NOTICES.txt file and licenses directory are provided in the ZIP.
- The new ZIP was validated for duplicate entries, CRC, font metadata, glyph coverage, MSDF bounds, local-only original asset preservation, and an offline V12 Minecraft integration test.

The original V9 release is retained as an **unpublished archive**; do not republish that archive with proprietary font files.
